# Onboarding Images

온보딩 시안에 사용한 이미지는 이 폴더에 저장하면 됩니다.

- `bg-tree-house.png`: page1, page2 배경
- `bg-meadow-house.png`: page3, page4, page5 배경
- `bg-castle-path.png`: page6 배경
- `lion-wave.png`: 인사하는 포포
- `lion-thinking.png`: 생각하는 포포
- `lion-backpack.png`: 가방 멘 포포
- `lion-side.png`: 옆모습 포포
- `lion-flag.png`: 깃발 든 포포
- `lion-reading.png`: 책 읽는 포포
- `lion-headphones.png`: 헤드폰 포포
- `lion-magnifier.png`: 돋보기 포포
- `lion-bird.png`: 새를 안은 포포
- `adventure-bag.png`: 모험 가방
- `apple.png`: 사과
- `banana.png`: 바나나
- `peach.png`: 복숭아

파일을 넣은 뒤 `src/pages/OnboardingPage/OnboardingPage.tsx`와
`src/pages/OnboardingPage/OnboardingPage.module.css`에서 `/images/onboarding/파일명.png`로 연결하면 됩니다.

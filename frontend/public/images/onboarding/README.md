# Onboarding Images

온보딩 시안에 사용한 이미지는 이 폴더에 저장하면 됩니다.

권장 파일명:

- `bg-tree-house.webp`: page1, page2 배경
- `bg-meadow-house.webp`: page3, page4, page5 배경
- `bg-castle-path.webp`: page6 배경
- `lion-wave.webp`: 인사하는 포포
- `lion-thinking.webp`: 생각하는 포포
- `lion-backpack.webp`: 가방 멘 포포
- `lion-side.webp`: 옆모습 포포
- `lion-flag.webp`: 깃발 든 포포
- `lion-reading.webp`: 책 읽는 포포
- `lion-headphones.webp`: 헤드폰 포포
- `lion-magnifier.webp`: 돋보기 포포
- `lion-bird.webp`: 새를 안은 포포
- `adventure-bag.webp`: 모험 가방
- `apple.webp`: 사과
- `banana.webp`: 바나나
- `peach.webp`: 복숭아

파일을 넣은 뒤 `src/pages/OnboardingPage/OnboardingPage.tsx`와
`src/pages/OnboardingPage/OnboardingPage.module.css`에서 `/images/onboarding/파일명.webp`로 연결하면 됩니다.
